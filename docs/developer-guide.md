# Developer Guide

Welcome to the Real Estate CRM documentation! We use a modular documentation structure to keep the repository clean and easy to navigate.

Please refer to the following documents based on what you need to do:

- **[Architecture Overview](./architecture.md):** Understand the Next.js App Router, Server Actions, and styling stack.
- **[Database Schema](./database.md):** Details on our PostgreSQL setup, Prisma models, and relationships.
- **[API & Webhooks](./api.md):** Information on third-party webhooks and internal Next.js API routes.
- **[Deployment Procedures](./deployment.md):** Environment variables, Supabase connection pooling, and Vercel hosting.
- **[Testing & QA](./testing.md):** How to run local checks and verify optimistic UI states.
- **[Troubleshooting](./troubleshooting.md):** Fixes for common Prisma, NextAuth, and Vercel errors.

If you are looking to contribute to the codebase, please read our **[Contributing Guidelines](../CONTRIBUTING.md)** in the root directory first.
